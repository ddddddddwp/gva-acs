# TR-069 参数树参数名复制布局设计

## 背景

参数树已经完成 GVA 明亮/黑暗主题适配和参数名复制，但当前参数名单元格同时展示相对名称、完整路径和常显复制入口，值列也保留复制按钮。信息重复且操作密度过高，与 GVA 原有表格风格不协调。

本设计只调整参数表格中的复制交互和排版，不修改参数树数据、查询接口或主题变量。

## 目标

- 每行只展示一次完整参数名。
- 只保留参数名复制，移除参数值复制。
- 完整参数名可原生选择，超长路径不破坏表格布局。
- 复制入口弱化为行悬停/键盘聚焦时出现的小图标。
- 继续兼容 GVA 明亮和黑暗主题。

## 交互与布局

参数名列改为单行结构：

```text
Device.ManagementServer.ConnectionRequestURL                         [复制]
```

- 展示 `scope.row.name` 的完整路径，不再额外展示相对名称。
- 文字使用等宽字体、单行省略；Tooltip 展示未截断的完整参数名。
- 参数名文本保持 `user-select: text`，用户可以手工选中。
- 复制按钮位于单元格右侧，不参与文字截断宽度计算。
- 按钮默认弱化或隐藏，表格行 hover、按钮 focus-visible 时显示。
- Tooltip 固定为“复制参数名”，成功提示为“参数名已复制”。
- Clipboard API 失败时提示“复制失败，请手动选择参数名复制”。
- 空参数名禁用复制。

值列只展示原始值，不再渲染复制按钮、Tooltip 或复制成功提示。值的格式化和空值展示保持不变。

## 无障碍与主题

- 复制按钮提供 `aria-label="复制参数名"`。
- 键盘 Tab 可以聚焦按钮，focus-visible 时按钮必须可见。
- 按钮颜色、hover 背景、文字和 Tooltip 继续使用 Element Plus/GVA 主题变量。
- 不恢复固定的白色、灰色或其他只适用于浅色主题的表面颜色。

## 代码收敛

- 把通用 `copyText(text, target)` 收敛为只处理参数名的 `copyParameterName(name)`。
- 删除值复制相关模板、分支文案、样式和无用图标引用。
- 参数名单元格只保留一个可访问的复制入口，避免点击文本和点击按钮产生重复交互。
- 本设计取代 `2026-07-16-tr069-parameter-tree-theme-copy-design.md` 中“保留参数值复制”和“双行参数名展示”的部分；原主题适配设计继续有效。

## 测试与验收

- 契约测试确认只存在“复制参数名”，不存在“复制参数值”。
- 契约测试确认模板只展示一次完整参数路径。
- 测试成功、失败和空参数名三种复制分支。
- 测试复制按钮具有 aria-label，并可通过键盘聚焦显示。
- 现有参数树加载、搜索、节点切换、在线状态和主题测试继续通过。
- `npm run build` 成功。
- 明亮和黑暗主题下人工检查长参数名省略、Tooltip、hover 和 focus 状态。

## 非目标

- 不修改参数树后端接口、数据结构和查询策略。
- 不增加参数值复制、批量复制或整棵参数树导出。
- 不改变参数树入口、抽屉尺寸和左右区域比例。
