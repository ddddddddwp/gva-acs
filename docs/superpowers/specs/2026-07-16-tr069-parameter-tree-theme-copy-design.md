# TR-069 参数树主题与复制体验设计

## 背景

设备列表中的参数树抽屉当前使用固定的浅色 Tailwind 样式，例如 `bg-white`、`text-gray-*` 和 `border-gray-*`。这些颜色不会随 GVA 的明亮/黑暗主题切换。

参数表格当前只在“值”列提供一个悬浮后出现的复制图标；“参数名”列没有复制入口，也不能明确区分“复制参数名”和“复制参数值”。

## 目标

- 参数树抽屉完整跟随 GVA/Element Plus 的明亮与黑暗主题。
- 用户可以选择参数名文本，也可以通过点击完整参数名或专用按钮复制完整参数路径。
- 参数名复制和参数值复制具有明确、不同的提示。
- 保持参数树现有布局、查询方式、接口和只读定位不变。

## 设计

### 主题

移除参数树组件中的固定浅色背景、文字和边框颜色，改用 Element Plus 主题变量：

- 背景：`--el-bg-color`、`--el-fill-color-light`、`--el-fill-color-lighter`
- 文字：`--el-text-color-primary`、`--el-text-color-regular`、`--el-text-color-secondary`
- 边框：`--el-border-color-light`、`--el-border-color-lighter`
- 强调色：`--el-color-primary`

抽屉、顶部栏、左侧树、当前路径和右侧表格使用同一套变量，避免局部仍保持白底。滚动条颜色也改为主题变量。

### 参数名复制

参数名列保留相对名称和完整参数路径：

- 相对名称用于快速浏览。
- 完整参数路径允许原生文本选择。
- 点击完整参数路径复制 `scope.row.name`。
- 参数名旁提供常显的复制按钮，Tooltip 为“复制完整参数名”。

### 参数值复制

值列继续支持复制，但按钮 Tooltip 明确为“复制参数值”。参数名和值共用异步复制函数，并根据复制目标显示不同成功信息：

- 参数名：`参数名已复制`
- 参数值：`参数值已复制`

复制失败时显示错误提示，不再无条件报告成功。

## 错误处理

- 空参数名或空参数值不触发复制。
- Clipboard API 不可用或拒绝权限时显示“复制失败，请手动选择文本复制”。
- 复制失败不影响参数树浏览和参数查询。

## 测试与验收

- 契约测试确认参数树不再使用固定的 `bg-white`、`bg-gray-*`、`text-gray-*`、`border-gray-*` 表面样式。
- 契约测试确认参数名支持文本选择、点击复制和独立 Tooltip。
- 契约测试确认参数值复制具有独立 Tooltip。
- 契约测试确认复制逻辑等待异步结果并提供失败提示。
- 现有参数树只读、在线状态和设备 RPC 测试继续通过。
- `npm run build` 成功。
- 在 GVA 明亮和黑暗主题下检查抽屉、树、表格和悬浮/选中状态。

## 非目标

- 不修改参数树后端接口或数据结构。
- 不增加参数编辑、批量选择或 RPC 下发功能。
- 不改变参数树入口和现有布局比例。
