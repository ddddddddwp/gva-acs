# TR-069 设备操作列对齐设计

## 背景

设备列表的“同步参数”和“参数”是相邻的 Element Plus `el-button`，而“更多”由独立的 `el-dropdown` 包裹按钮。三者使用不同的行内基线规则，导致“更多”与前两个操作不在同一水平线，按钮间距也不统一。

## 设计

在设备列表操作列中增加一个仅负责布局的 `device-row-actions` 容器：

- 使用 `inline-flex`，保持内容在现有居中操作列中按内容宽度排列。
- 使用 `align-items: center`，让两个直接按钮和下拉按钮垂直居中。
- 使用统一的小间距，并清除 Element Plus 相邻按钮默认的额外左外边距。
- 保留现有 `type="primary"`、`link`、图标、禁用状态、加载状态和下拉菜单样式，继续遵循 GVA 的链接式操作风格。

## 范围

- 只修改 `web/src/plugin/tr069/view/device/index.vue` 的操作列标记和局部样式。
- 在现有设备页面契约测试中增加布局约束，防止后续删除 flex 容器或垂直居中规则。
- 不修改 RPC 功能、权限、菜单内容、危险操作确认、表格列宽或主题颜色。

## 验证

- 契约测试先证明当前页面缺少统一操作容器，再验证新增布局规则。
- 运行 TR-069 前端测试与生产构建。
- 在亮色和暗色主题下确认三个操作入口位于同一水平线，样式与 GVA 其他链接操作一致。
