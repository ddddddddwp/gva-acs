# TR-069 基站功能开发计划

根据您的要求，我们将分两步走：首先实现后端对 TR-196 基站参数模型的支持（数据存储与业务逻辑），然后开发前端页面进行展示和交互。

## 阶段一：后端开发 - TR-196 基站参数模型实现

**目标**：建立基站无线参数的数据库模型，并实现参数的查询与配置逻辑。

1.  **数据模型设计 (Model)**
    *   创建 `server/plugin/tr069/model/fap_service.go`
    *   定义 `FAPService` 结构体，映射 TR-196 关键参数：
        *   `PhysicalCellID` (PCI)
        *   `CellID` (ECGI)
        *   `EARFCNDL` / `EARFCNUL` (频点)
        *   `DLBandwidth` / `ULBandwidth` (带宽)
        *   `TxPower` (发射功率)
        *   `AdminState` / `OpState` (管理/运行状态)
    *   建立与 `Device` 表的一对一关联 (`DeviceID`)。

2.  **数据库迁移 (Migration)**
    *   更新 `server/plugin/tr069/initialize/gorm.go`，注册 `FAPService` 模型以自动建表。

3.  **业务逻辑层 (Service)**
    *   创建 `server/plugin/tr069/service/fap.go`
    *   实现 `GetFAPInfo(deviceID)`: 从数据库查询基站参数。
    *   实现 `SyncFAPInfo(deviceID)`: **关键逻辑** —— 创建一个 TR-069 `GetParameterValues` 任务，放入队列，等待设备下次心跳时下发，以获取设备侧真实的无线参数。
    *   实现 `ConfigureFAP(deviceID, config)`: 创建 `SetParameterValues` 任务，用于修改基站参数。

4.  **API 接口层 (Controller)**
    *   创建 `server/plugin/tr069/api/fap.go`
    *   提供 HTTP 接口供前端调用：
        *   `GET /tr069/fap/:deviceId`: 获取参数。
        *   `POST /tr069/fap/:deviceId/sync`: 触发同步。
        *   `PUT /tr069/fap/:deviceId`: 下发配置。
    *   注册路由到 `server/plugin/tr069/router/fap.go`。

## 阶段二：前端开发 - 基站管理页面

**目标**：提供可视化的界面来查看和配置基站参数。

1.  **API 对接**
    *   创建 `web/src/plugin/tr069/api/fap.js`，封装上述后端接口。

2.  **基站配置组件**
    *   创建 `web/src/plugin/tr069/view/device/components/fap-info.vue`
    *   **展示区**：使用 Descriptions 组件展示当前的 PCI、频点、带宽等信息。
    *   **操作区**：
        *   "刷新数据" 按钮：调用 `Sync` 接口。
        *   "修改配置" 按钮：弹窗表单，允许用户修改 PCI 和 发射功率。

3.  **集成到设备详情页**
    *   修改设备列表页，增加“基站详情”入口，或者在点击设备时展开该组件。
