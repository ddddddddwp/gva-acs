# TR-069 基站/专网设备功能开发指南

本文档专门针对**基站（Small Cell/Femtocell）**、**CPE（4G/5G）**及**专网通信设备**的管理需求进行了裁剪和优化。相比于家庭网关，此类设备更关注无线射频参数、网络稳定性及位置服务。

## 1. 基础连接与认证 (Basic Connectivity)

*   **双向认证 (Mutual Authentication)**:
    *   **重要性**: 基站设备通常部署在不安全的公共网络环境中，必须启用严格的双向 TLS 认证（mTLS），防止伪造基站接入。
*   **IPSec/VPN 隧道监控**:
    *   **功能**: 监控设备与核心网（Core Network）之间的安全隧道状态。
    *   **关键参数**: `Device.IPsec.Tunnel.{i}.Status`
*   **心跳保活优化**:
    *   **功能**: 针对不稳定的回传网络（Backhaul），优化 `PeriodicInformInterval`（周期上报间隔），平衡服务器负载与监控实时性。

## 2. 射频与无线参数管理 (RF & Radio Management)

这是基站设备区别于普通路由器的核心功能。

*   **小区配置 (Cell Configuration)**:
    *   **功能**: 下发和查询小区标识、频点等关键参数。
    *   **常用参数**:
        *   `PhysicalCellID` (PCI): 物理小区标识。
        *   `EARFCN` / `NR-ARFCN`: 绝对无线频道编号（4G/5G）。
        *   `TAC` / `LAC`: 跟踪区代码/位置区代码。
        *   `TxPower`: 发射功率控制（防止干扰宏站）。
*   **邻区关系管理 (Neighbor Relations)**:
    *   **功能**: 配置自动邻区关系（ANR）或手动下发邻区列表，保障终端在不同基站间平滑切换（Handover）。
*   **干扰扫描 (REM - Radio Environment Monitoring)**:
    *   **功能**: 周期性扫描周边无线环境，上报干扰源和信号强度，供网规网优系统（SON）使用。

## 3. 状态监控与性能指标 (KPI Monitoring)

基站运维高度依赖 KPIs（关键性能指标）。

*   **RRC 连接数**:
    *   **功能**: 实时监控当前连接的用户数（Active Users），评估基站负载。
*   **吞吐量统计**:
    *   **功能**: 上行/下行流量统计，用于计费或扩容参考。
*   **切换成功率**:
    *   **功能**: 监控 Handover Success Rate，识别网络覆盖盲区或参数配置错误。

## 4. 位置与同步 (Location & Synchronization)

*   **GPS/北斗状态**:
    *   **功能**: 监控卫星锁定状态，确保基站时钟同步（对 TDD 系统至关重要）。
*   **IEEE 1588v2 (PTP)**:
    *   **功能**: 在无法接收卫星信号的室内场景，监控 PTP 时钟同步状态。
*   **地理位置上报**:
    *   **功能**: 上报经纬度信息，用于资产盘点和覆盖图绘制。

## 5. 告警与故障处理 (Alarm & Fault Management)

*   **关键告警**:
    *   **场景**: 射频单元（RRU）过热、驻波比（VSWR）异常、时钟失锁、S1/X2 接口中断。
    *   **处理**: ACS 收到此类 Alarm 后需立即通过短信/邮件通知运维人员。
*   **看门狗与自愈**:
    *   **功能**: 监测到核心进程崩溃或长时间无流量时，自动执行软重启。

## 6. 批量升级与配置 (Bulk Operations)

*   **分区域升级**:
    *   **场景**: 按照基站所在的地理区域（如：某市某区）或归属的核心网网元（MME/AMF）进行批量固件升级。
*   **配置一致性检查**:
    *   **场景**: 确保同一区域内的基站使用统一的软件版本和无线参数模板。

---

**技术实现建议**:

1.  **模型扩展**: TR-069 标准数据模型（TR-098/TR-181）对基站支持有限，通常需要支持 **TR-196 (Femto Access Point Service Data Model)** 数据模型。请确认您的 ACS 解析器能兼容 Vendor-Specific 参数。
2.  **高频数据处理**: 射频扫描数据（REM）量大且频繁，建议直接通过 HTTP Upload 上传文件，而不是通过 Inform 报文携带大量参数。
