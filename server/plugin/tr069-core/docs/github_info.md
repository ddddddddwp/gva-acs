```
origin  https://github.com/ddddddddwp/tr069-core.git (fetch)
origin  https://github.com/ddddddddwp/tr069-core.git (push)
```

## 常用 Git 命令

### 查看远程仓库配置
```bash
git remote -v
```

### 更新远程仓库地址
```bash
git remote set-url origin https://github.com/ddddddddwp/tr069-core.git
```

### 提交更改
```bash
git add .
git commit -m "提交说明"
```

### 推送到远程仓库
```bash
git push origin V1
```

### 拉取远程更新
```bash
git pull origin V1
```

## 注意事项

- 推送代码前请确保已经提交所有更改
- 如遇到推送失败，可能是网络问题或权限问题，请稍后重试
- 确保在正确的分支(V1)上进行开发和提交
